# Anna Chatbot

Anna Chatbot is a web-based chatbot developed in 2020 for practicing English through text-based conversations.

The system was built using PHP and MySQL and includes an Admin Dashboard for managing chatbot content and responses.

Unlike modern AI chatbots, Anna does not use external AI APIs or large language models (LLMs). The chatbot uses predefined and database-driven responses to interact with users.

## Features

- English conversation practice
- Text-based chatbot interface
- Rule-based chatbot responses
- MySQL database integration
- Admin Dashboard
- Manage chatbot responses
- Manage conversation data
- PHP-based backend

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP
- phpMyAdmin

## About the Project

This project was originally developed in 2020, before modern generative AI tools and LLM APIs became widely available.

Anna Chatbot demonstrates a traditional approach to building a chatbot using PHP, MySQL, predefined responses, and rule-based conversation logic.

## Running Locally

1. Install XAMPP.
2. Copy the project folder into `htdocs`.
3. Start Apache and MySQL.
4. Create the required database in phpMyAdmin.
5. Import the included `.sql` database file.
6. Configure the database connection if necessary.
7. Open the project through `localhost` in your browser.
